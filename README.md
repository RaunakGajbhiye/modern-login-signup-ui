# Modern Login & Sign Up UI

A clean split-screen Sign In and Create Account interface built with HTML & CSS.

## Features
- Split-screen layout with Sign In and Create Account views
- Email & password inputs with toggle visibility
- Social login buttons (Google, Facebook, X)

## Usage
Open `auth.html` directly in your browser.
